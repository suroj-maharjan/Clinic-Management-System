# Clinic-Management-System
This is a django project for learning with AWS S3 file storage and PostgreSQL.

## Purpose
This application helps the client to book an online appointment in the clinic, and choose the suitable time and doctor as required.

## Features
Upload and retrieve files via S3
Web-based application for online booking

## Tech Stack
Python, Django, PostgreSQL, Bootstrap, AWS S3


## What I Learned
This is a project I developed for self-learning purpose, and I learned how to connect with database and upload files into S3 via django and make CRUD application using python django.
